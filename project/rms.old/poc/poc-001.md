<h1 align="center">Project: RCtl : POC-001</h1>

Target URI & Path Parser




# Objective

Validate the core CLI parsing logic by implementing a zero-dependency Go package (`pkg/target`) that parses raw command-line targets into structured, validated domain objects according to [ADR-004][adr004 whatis].

# Input / Output Contract

* **Input:** A raw target string (e.g., `git:my-org/my-repo/branches`) and optional positional verb/flags.
* **Output:** A structured `Target` struct or a descriptive parsing error.

```go
type Target struct {
    Raw      string // "git:my-org/my-repo/branches"
    Prefix   string // "git"
    Path     string // "my-org/my-repo"
    Subpath  string // "branches"
    IsScoped bool   // true
}

```

# Scope & Requirements

* **Prefix Extraction:** Split on the first colon (`:`) to isolate the driver domain prefix (e.g., `git`, `container`, `pkg`, `file`, `s3`).
* **Path & Subpath Resolution:** Parse the remaining path string using POSIX-style path rules:
* First segment(s) form the root resource `Path`.
* Trailing segment(s) form the child resource `Subpath`.


* **Validation Rules:**
* Reject targets missing a scheme prefix (e.g., `my-org/my-repo` without `git:`).
* Reject empty paths or invalid characters (e.g., `git:` or `s3://`).
* Normalize redundant slashes (e.g., `git:org//repo` $\rightarrow$ `git:org/repo`).



# Deliverables

1. **`pkg/target/parser.go`**: Core parsing logic and error definitions.
2. **`pkg/target/parser_test.go`**: Table-driven unit tests covering edge cases:
* Standard root resources (`git:org/repo`)
* Deeply nested path scopes (`git:org/repo/branches/main`)
* Non-repository providers (`s3:my-bucket/logs/app.log`, `file:/etc/app/config.json`)
* Invalid URIs (missing prefix, empty string, malformed characters)
3. **`cmd/poc-parser/main.go`**: A lightweight CLI test binary that reads a target string from `os.Args` and prints the JSON-serialized `Target` struct to `stdout`.
