<h1 align="center">MetaDoc System</h1>


# Definition
A **System**:
- Denotes something considered as a whole or part of a whole.
- Can be composed of other Systems.
- Does not necessarily have to be decomposed into smaller Systems.
- Is sometimes referred to as a Platform
- A system's final denomination depends on a lot of characteristics, like its capabilities, implementation, ...:
  - In software development, it could end-up in a platform, framework, software, tool, CLI, ...


## Example

- An **organization** can be considered a System.
- A **department** can be a System that is part of an organization.
- A **software application** can be a System (e.g. `Kubernetes`, `OpenStack`).
- A **component** of an application can also be considered a System.
- A **document** can be considered a System if it is treated as a whole, even if it contains other elements.
- **Kubernetes**, considered as a **system** can also be considered a **Platform** when other Systems run on or use it.
- **MetaDoc**, considered as a **system** can also be considered a **Platform** because it provides capabilities for managing documentation.
