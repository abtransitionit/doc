<h1 align="center">MetaDoc Domain</h1>

# Create a Domain
1. Suppose you want to write a documentation about `Kubernetes` (i.e. the topic). 
1. You decide the [domain](../whatis/domain.md) of the documentation is **system**
1. create the folder `<DocRoot>/<domain>` (i.e. `<DocRoot>/system`)
1. That's it. The domain is ready to host [DoocSets](../whatis/docset.md)
1. [Create the DocSet](../howto/docset.md#create-a-docset-for-a-topic) for your topic
