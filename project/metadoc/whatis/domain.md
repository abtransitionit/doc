<h1 align="center">MetaDoc Domain</h1>

# Definition
- A folder under [DocRoot](../whatis/docroot.md)
- Hosts a collection of [DocSets](../whatis/docset.md)
- The name of a **Domain** identifies the kind of documentation it contains.


# Example 
- Domain:`<DocRoot>/project` contains [DocSets](../whatis/docset.md) that each document a **Project**
- Domain:`<DocRoot>/os` contains [DocSets](../whatis/docset.md) that each document an **OS**
