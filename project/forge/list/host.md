<h1 align="center">List of Forge Host</h1>

# List


## Physical hosts
* Server, Desktop PC, Laptop, Workstation, Raspberry Pi
* Physical server, Bare-metal server
* Blade server
* Rack server
* Tower server
* Other ARM SBCs
* Network appliance capable of running an OS
* Storage appliance / NAS
* Mainframe
* Supercomputer node
* HPC compute node
* Industrial computer
* Edge computer
* IoT computer, if it runs a general-purpose OS
* physical Kubernetes node


## Virtual hosts
* VMware
* KVM
* QEMU
* libvirt
* Hyper-V
* Xen
* bhyve
* VirtualBox
* Proxmox
* AWS EC2 instance
* OpenStack Instance
* Azure Virtual Machine
* Google Compute Engine instance
* Oracle Cloud VM
* DigitalOcean Droplet
* Scaleway instance
* Hetzner Cloud server
* virtual Kubernetes node
*  ...

Also:
* Firecracker microVM
* Kata Containers VM
* Nitro-based virtual machine
* Confidential VM

## Container Host

* Docker container
* Podman container
* LXC/LXD container
* Kubernetes Pod/container
* ECS task
* Cloud Run container
