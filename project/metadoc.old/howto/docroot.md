<h1 align="center">MetaDoc DocRoot</h1>

# How to create a DocRoot

- Any folder can be the `DocRoot` of a `MetaDoc` documentation system.
- A folder becomes a `DocRoot` when its content follows the MetaDoc [rules](../list/rule.md).
