<h1 align="center">MetaDoc DocSet</h1>

# Definition
- A documentation on a **topic** (e.g. `kubernetes`, `linux`)
- a set of files and folders under a [Domain](../whatis/domain)

# Properties
- The **entry point**: the file `<domain>/<topic>/whatis/ep.md`
- The **name**: `<topic>`
- The **kind**: `<domain>`

# Key Points
- the `<domain>` qualify the kind of the **topic**'s documentation
