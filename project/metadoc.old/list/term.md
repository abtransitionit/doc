# Extensibility vs. scalability
in a code context

**Extensibility**

* Is about capability (adding new features without breaking the existing system).
* Grows in terms of **functionality** (plugins, custom components, integration hooks).

**Scalability**

* Is about volume (handling higher demand without degrading performance).
* Grows in terms of **capacity** (more pages, higher traffic, larger contributors).
