### Core Navigation Rules

* **System Truth (`concept/`, `language/`, `software/`):** Permanent manuals and live system states. Edits occur only when features or specifications ship.
* **Active Execution (`project/`):** Work in progress (Draft RFCs, Sprint logs, Task boards). Upon project completion, approved specs are promoted to their respective Evergreen directory.
