### Core Navigation Rules

* **System Truth (`concept-hub`, `language-hub`, `software-hub`):** Documents here represent permanent manuals and live system states. Edits occur only when features or specifications ship.
* **Active Execution (`project-hub`):** Documents here represent work in progress (Draft RFCs, Sprint logs, Task boards). Upon project completion, approved specs are promoted to their respective Evergreen Hub.
