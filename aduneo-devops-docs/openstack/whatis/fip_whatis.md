# Definition
- is1 Acronym for Floating IP
- Allow to associate 1 Ip to 1 Ip
- Is used in folowing Use Case
  - Load Balancing via Reverse Proxy
  - Fautl Tolearnce of Type Primary/Secondary (i.e Active/Inactive)
  - To Associate/De-Associate Ip@Public to Ip@Private

# Operation

|Id|Name|See|Description|
|-|-|-|-|

||Delete|Create|Delete Object in ops

||Dissociate|Asociate|<li>Remove Assicoiation</li><li>Keep Object in ops</li>
