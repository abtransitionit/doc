# Terraform > C'est quoi


Terraform est 
  - 1 outil OpenSource
  - édité par l'organisation Hashicorp
  - écrit en go
  - 1 Cli

Terraform permet 
  1. d'abord de faire de l'Iac (e.g create, update, delete des infrastructures) sur les principaux cloud
    - VmWare, Aws, Openstack, Gcp, Azure
  1. ensuite d'effectuer d'autres actions sur les Vms de cette infra
