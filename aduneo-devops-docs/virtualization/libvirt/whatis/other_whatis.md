# Definition
## qemu-kvm
- An opensource emulator and virtualization package that provides hardware emulation.
## virt-manager
- Gui to manage Vm via daemon:libvirt
## virsh
- Cli to manage Vm via daemon:libvirt
## libvirt-daemon-system
- File@Conf used by daemon:libvirt
## virtinst
- Tool to Manage (i.e provision, modify) Vm 
## libvirt-clients
- set of Cli to manage Vm and Hypervisor
## bridge-utils
- set of Cli to manage (create) bridge devices.
