# List of numbers 20-90

- to count the pattern is to add **een** (exception for 20)
- The literal translation of the number 21 would be 1 and 20,
- so 21 = <span style="font-size: 32px;">واحد وعشرين</span>   = wahed wa eshreen = 1 and 20
- so 22 = <span style="font-size: 32px;">اثنين وعشرين</span>  = ethnein wa eshreen = 2 and 20
- ...
