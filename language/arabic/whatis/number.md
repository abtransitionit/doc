# Numbers: 10-17
- To count, the pattern is **ʿashar*** (10)
- The literal translation of the **13** would be **3 and 10**
- so 13 = \<span style="font-size: 32px;">ثلاثة عشر\</span> = thalatha ʿashar = 3 ten
- so 14 = \<span style="font-size: 32px;">أربعة عشر\</span> = arba’a ʿashar = 4 ten
- ...
- so 19 = \<span style="font-size: 32px;">تسعة عشر\</span> = tes’a ʿashar = 9 ten

# Numbers 1000-9000


- To count, the pattern is **alaaf** (exception for 1000 and 2000)
- The literal translation of the number **1243** would be **1000 and 200 and 3 and 40**
- so **1240** = <span style="font-size: 32px;">ألف ومائتين وأربعين</span> = **1000 and 200 and 40** = Alf o me’tin o arba’een
- so **2320** = 2000 and 300 and 20 = Alfe•in o thalath.me’aa o eishr•in
- **1000** is a special form: **ألف** = Alf
- **2000** is a special form: **ألفين** = Alfe•in
- **3000–9000** use the plural **آلاف (aalaaf)**:
  * 3000 = ثلاثة آلاف
  * 4000 = أربعة آلاف
  * 5000 = خمسة آلاف
  * 6000 = ستة آلاف
  * 7000 = سبعة آلاف
  * 8000 = ثمانية آلاف
  * 9000 = تسعة آلاف

**One important correction to the counting rule:** for numbers such as **3000**, the Arabic is **ثلاثة آلاف**, not *ثلاث آلاف*. The thousands from 3000–9000 use the feminine forms **ثلاثة، أربعة، خمسة...** followed by **آلاف**.
