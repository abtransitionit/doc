<h1 align="center">What is Linux User</h1>

# Kind
- Unprivileged users 
- Privileged user: root 

# User UID
**0-999**: 
- Reserved for system accounts (e.g. **root**, **www-data**, **sshd**). 
- These are used by services and daemons.

**1000-**: 
- Used for regular users.
- **1000**: The first, non-privileged "regular" user on a Linux system.
