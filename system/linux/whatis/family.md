## RHEL family

DNF (**D**a**n**di**f**ied YUM) is the default package manager for the **Red Hat-based** Linux distribution family. 
It is used to install, update, and manage **RPM** software packages. 

This package management family primarily includes:
- **Fedora** (where DNF was first introduced)
- Red Hat Enterprise Linux (**RHEL**) (starting with RHEL 8)
- **CentOS** Stream / CentOS
- **Rocky** Linux
- **AlmaLinux**
- **Oracle** Linux 

## Debian family

APT (**A**dvanced **P**ackage **T**ool) is the package management system used for the **Debian-based** Linux distribution family. It works behind the scenes with **dpkg** to install, update, and manage .deb software packages.

This package management family primarily includes:
- **Debian** (the foundation of the family)
- Ubuntu (and its flavors like **Kubuntu**, **Xubuntu**, and **Lubuntu**)
- Linux **Mint**
- **Pop**!_OS
- **Kali** Linux
- **Raspberry** Pi OS (formerly Raspbian)
