<h1 align="center">Documentation Howtos</h1>

# Purpose

This document defines how to manage documents into the organization's IT documentation.


# Add a new document
1. Define the document type
1. Each document is a folder with at least a `README` files in its root.
1. Create a folder from scratch with that README file **or** copy past an existing folder, you will modify.

# Bootstrap a project
1. [Add a new document](#add-a-new-document)
1. Create a roadmap or a simple plan specifying the duration of each project milestone, phase, or stage.
1. As the project progresses, add files to the project and update the roadmap.
