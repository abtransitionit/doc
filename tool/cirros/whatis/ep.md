<h1 align="center">What is CirrOS</h1>


# Definition
- A tiny (under 13 MB), fast-booting Linux distribution built with BusyBox and Buildroot.
- Used exclusively in cloud [OpenStack][openstack whatis] or **Proxmox**
- A proof-of-concept test image to verify that hypervisors, VM launches, and networking work properly.
-  Has well-known default login credentials (cirros with passwordless sudo access).
