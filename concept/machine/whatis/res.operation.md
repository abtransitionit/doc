<h1 align="center">What is a Resource Operation</h1>



# Definition

- An action made on a resource
- Often represented as **verb**
- Is often resource-specific. 

# Example

|resource|operation|
|-|-|
|go-module|init, list|
|git repoitory|clone, reset-history, delete|
|container|start, stop, configure|
|container image|create, instanciate, configure|

# Kind
- some operation have a name that has semantic for several resource
