# Definition


## Model Runtime
- aka. **Local (LLM) Inference/Execution Engines**
- a tool that runs AI models on a local computer or server
- An [inference engine][whatis inference engine] + wrapper around it that add
    - AI model management
    - API
- allows to 
    1. Download AI models.
    1. Run them locally.
    1. Talk to them via a CLI/GUI/SDK.
