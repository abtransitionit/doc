# Definition
a registry/repository/store for free and paied
- **AI models**: 
    - More than 3 millions
- **Datasets**: 
    - The raw material used to train and test models. 
    - More than 1 million public datasets
- **Spaces**: 
    - Live, interactive demo apps you can try in your browser.
    - built with **Gradio**, **Streamlit**, **Docker**, or plain **HTML** 
    - More than 2 million of them, 
- **Storage Buckets**:
    - Simple, large-scale file storage (like AWS S3). 
    - Used for checkpoints, logs, and intermediate files that don't need version history
- **Other**    
    - Libraries & Tools
    - code that connects to the Hub, like **transformers** (for models) and **datasets** (for data)
