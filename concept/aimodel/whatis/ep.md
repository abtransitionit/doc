# Definition
- A computer program
- Learns patterns from data
- Uses patterns to make predictions or decisions


# Operation
- create
- package
- distribute
- use

**Create an AI Model**

1. design
1. train on data
1. produces the weights

**Package an AI Model**

Create a set of files containing the "learned patterns" (weights), plus some code that knows how to run them.

**Distribute an AI Model**

- Downloaded like an app from a website, app store, or package registry (e.g., Hugging Face, pip, npm), often as a single file you can copy around.

**Use an AI Model**

1. agent feed input (text, image, etc.), 
2. Model runs the math on its weights
3. Model outputs a result.

This can happen on your device, on a server, or via an API call to someone else's server.
