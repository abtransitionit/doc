<h1 align="center">What is a Project Roadmap</h1>

The concept of project roadmap

# Definition

A **Project Roadmap** is a roadmap applied to a project, expressing the project's direction from start to delivery through ordered phases, milestones, and deliverables, built on top of the project lifecycle.

## Project roadmap
- A [rm][home topic] applied to a [project][project whatis].
- Shows the **direction of the project** from start to delivery.
- Built on top of the project [lifecycle][lfc whatis] — the lifecycle gives the stages, the roadmap gives the order, milestones, and direction.
- Communicates to stakeholders *where the project is going* and *how progress is measured*.

## What it is not
- Not a detailed plan (that is the plan).
- Not a schedule (that is the schedule).
- Not the lifecycle itself (the lifecycle is the set of stages).

## Relationship to the project
- A project **uses** a roadmap to represent its path.
- The roadmap **depends on** the project: without a project, a project roadmap has no subject.

# Composition

| Element | Role in a project |
| ------- | ----------------- |
| **Horizon** | The project's time window |
| **Phases** | The project lifecycle stages, put in order |
| **Milestones** | Key project checkpoints (delivery, review, release) |
| **Deliverables** | What the project produces at each milestone |
| **Direction** | The project's target outcome |
