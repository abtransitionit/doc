<h1 align="center">How-to for Software Requirement</h1>

The concept of Software Requirement

# Methodology

## Produce a first list of requirements

1. **Take the software project vision** and read it line by line.
1. For each sentence that expresses a need, expectation, obligation, or constraint → **candidate requirement**.
1. Give each candidate: `ID`, `Title`, `Statement`, `Source` (the vision line), `Rationale`.
1. Set `Version = 0.1`, `Status = draft`. Don't debate wording yet.
1. Group by `Kind` (Functional / Non-functional) — don't sort by priority yet.
1. use a [template][tpl whatis] to register requirments

## Review the status
1. Review with stakeholders → status moves to `proposed` → `agreed`.
