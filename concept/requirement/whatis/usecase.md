<h1 align="center">What is a Use case</h1>

The concept of Software Requirement

# Definition
- a concrete, end-to-end **story** that exercises several requirements at once
- it allows to see:
  - which requirements are really needed
  - which are missing
  - which are wrong
  - What the system actually looks like from the outside.
