<h1 align="center">What is a Software Project</h1>

The concept of software project


# Definition
- a [project][project whatis] that leads to/output a [software][tool whatis]
- has a specific well known lifecycle (from best practices of CMMI, ITIL, PRINCE, ...)

# Example of a Software Lifecycle

<!-- A software lifecycle is usually adapt to a domain, context and many other **constraints** -->

| Lifecycle | representation of the lifecycle's phases |
|-|-|
| [Example 1](#software) | `development` → `testing` → `deployment` → `operation` → `retirement`
| [Example 2](#project) | `initiation` → `planning` → `execution` → `closure`
| [Example 3](#sproject) | `vision` → `domain` → `model` → `prototype` → `implementation` → `validation` → `release` → `operation`|
| [Software](#software) | `development` → `testing` → `deployment` → `operation` → `retirement`
| [Software Project](#sproject) | `vision` → `domain` → `model` → `prototype` → `implementation` → `validation` → `release` → `operation`|
