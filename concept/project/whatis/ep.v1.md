<h1 align="center">Project</h1>

# Definition
Takes **inputs** and activities/work to create **outputs** that provide value to a stakeholder, often in the form of a product, service, or result.

```
Project → creates → Product/Service → provides → Value
```

# Key Characteristics of a project

- **Temporary**: has a defined start and end
- **Unique**: produces something new or different
- **Constrained**: limited by time, cost, scope, and resources

---


- Uses inputs
- Performs project work/activities
- Produces outputs: **product**, **service**, or **result**
→ That enable/create/generate outcomes and value

---

- The product/service operations can continue without a project after the project has created them.

---

-  Example of **inputs**: ideas, needs, materials, knowledge, or requests.
-  Example of **outputs**: deliverables, artifacts, activities, or outcomes.

---


---

But if you're learning project management, this formulation blurs an important distinction:
- A project is a temporary endeavor undertaken to create a unique product, service, or result.
- A product/service/result is what the project delivers.
---

- **projects**, **products**, or **services** all have a [lifecycle][lifecycle whatis]

---
- Project = temporary work to create something unique.
- Operations = ongoing work that repeatedly produces/delivers products or services.
---


- A project uses inputs and activities to produce outputs
- Output may be **product**, **service**, or **result** and provides value to stakeholders

---

- A project is a **temporary endeavor** undertaken to create a unique product, service, or result.
- A **product/service/result** is what the project **delivers**.



# Kind

| Category | Examples |
|----------|----------|
| **Physical Products** | Cars, furniture, electronics, clothing, buildings |
| **Digital Products** | Mobile apps, websites, SaaS platforms, AI models |
| **Services** | Consulting, healthcare, education, repair, logistics |
| **Internal Projects** | Process improvement, team restructuring, policy development |
| **Creative Works** | Films, books, marketing campaigns, art installations |
| **Nonprofit / Social** | Community programs, disaster relief, advocacy campaigns |
| **Personal** | Fitness goals, learning paths, relocation plans |
| **Hybrid** | Product-as-a-service (e.g., subscription boxes), platform ecosystems |
