<h1 align="center">What is POC</h1>

The concept of POC

# Definition
## POC
- stands for **P**roof **o**f **C**oncept
- answers the question: « Est-ce que notre idée fonctionne techniquement ? »
- validates a specific technical or conceptual hypothesis.

- Purpose: 
  - apprendre et valider la faisabilité, 
  - pas construire le produit mais apprendre à le construire 
  - créer un prototype technique de production
On cherche surtout à **prouver que les briques essentielles peuvent fonctionner ensemble**.

Le POC peut être très moche :

* pas de vraie interface ;
* peu ou pas de sécurité ;
* code provisoire ;
* données éventuellement en fichiers JSON ;
* APIs appelées directement ;
* un seul utilisateur ;
* un seul fournisseur par service.

Le POC doit donc rester **jetable et rapide**, sans chercher à anticiper toute l'architecture du produit final.

> Principe: **Faire fonctionner la chaîne complète avant de chercher à la rendre belle, robuste ou scalable.**

C'est volontairement beaucoup plus léger. **Le seul objectif du POC : obtenir une vidéo à partir d'un sujet, automatiquement.** Ensuite seulement, on industrialise ce qui a prouvé son intérêt.
