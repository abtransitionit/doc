# POC vs. MVP


```text
                 IDÉE
                   ↓
                 POC
          "Est-ce possible ?"
                   ↓
            Validation technique
                   ↓
                 MVP
        "Est-ce utilisable ?"
                   ↓
          Produit / V1
       "Est-ce industrialisable ?"
```


|                     | POC                   | MVP                    |
| ------------------- | --------------------- | ---------------------- |
| But                 | Prouver               | Utiliser               |
| Durée               | Très courte           | Plus longue            |
| Qualité du code     | Provisoire acceptable | Structurée             |
| UI                  | Optionnelle           | Nécessaire             |
| Base de données     | Pas forcément         | Oui                    |
| Sécurité            | Minimale              | Réelle                 |
| Gestion erreurs     | Basique               | Robuste                |
| Utilisateurs        | Développeur           | Utilisateur            |
| Architecture        | Peut être simplifiée  | Doit être durable      |
| Critère de réussite | **Ça marche**         | **On peut l'utiliser** |
