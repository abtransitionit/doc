<h1 align="center">What is a MVP</h1>

The concept of MVP

# Definition
## MVP
- stands for **M**inimum **V**iable **P**roduct
- answers the question: « Peut-on construire une première vraie version utilisable du produit ? »
- validates the core product proposition through a usable product.

Il reprend ce qui a été validé dans le POC et ajoute les fondations nécessaires :

* vraie architecture ;
* frontend ;
* backend ;
* base de données ;
* authentification ;
* workflows robustes ;
* gestion des erreurs ;
* stockage ;
* historique ;
* monitoring minimal ;
* expérience utilisateur cohérente.

Le MVP doit être **utilisable**, même s'il reste limité.
