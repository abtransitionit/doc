<h1 align="center">What is a Environment</h1>

The concept of Environment


# Definition
- Aka. Execution Environment
- A compute-capable context
- In which resources are provisioned and executed

# Kind
- Atomic    — e.g. 1 container, 1 VM, 1 bare-metal
- Composite — e.g. 1 cluster of containers / VMs / bare-metal
