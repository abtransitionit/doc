# List of Container Image registry <a id='registry'></a>

Well-known OCI container registries that support **OCI** or **Docker-compatible** container images

| Registry                                | Provider / purpose                    | Registry address                           |
| --------------------------------------- | ------------------------------------- | ------------------------------------------ |
| Docker Hub                              | Popular public registry               | `hub.docker.com`                           |
| GitHub Container Registry (**GHCR**)        | Integrated with GitHub                | `ghcr.io`                                  |
| GitLab Container Registry               | Integrated with GitLab CI/CD          | `registry.gitlab.com`                      |
| Amazon Elastic Container Registry (**ECR**) | AWS                                   | `<account>.dkr.ecr.<region>.amazonaws.com` |
| Google Artifact Registry                | Google Cloud                          | `<region>-docker.pkg.dev`                  |
| Azure Container Registry (**ACR**)          | Microsoft Azure                       | `<name>.azurecr.io`                        |
| Red Hat Quay                            | Public and private image repositories | `quay.io`                                  |
| Harbor                                  | Self-hosted, open-source registry     | Your own hostname                          |
| JFrog Artifactory                       | Enterprise artifact management        | Your own hostname                          |
| DigitalOcean Container Registry         | DigitalOcean cloud                    | Provider-assigned hostname                 |
